    -> ServiceNow is running over 100 Billion Workflows Per Year.

    -> Workflow = Work + Flow (Work Flowing) i.e 
    How Work Moves From One Step To Another Step Until It's Finished.

    -> Real Life Workflow - Ordering Food Online 

        -> Open Food Delivery App 

        -> Select Restaurant 

        -> Choose Food From Menu 

        -> Add To Cart 

        -> Pay For Order 

        -> Restaurant Receives Order 

        -> Food Being Prepared 

        -> Delivery Partner Picks Up Order 

        -> Order Delivered 

    
    -> In Terms Of Business 

        -> A Workflow Is The Path A Task Follows From 

            -> Request -> Approval -> Action -> Completion 

        
    -> Real IT Support Workflow 

        TCS - Real Company Example 

        Employee Says - "My Laptop Is Not Working"

    
    -> Step 1: Employee Raises A Ticket 

        My Laptop is not starting - Submitted Via IT Portals or Help desk Tool 

    -> Step 2: Manager Approval 

        Manager Reviews Request and Approves it (New Replacement / Repair)

    -> Step 3: IT Team Receives Request 

        Tickets Will Be Generated - Teams Will Be Notified 

    -> Step 4: Technician Checks Issues 

        Technician Visits and hands over Laptop 

        Technician Diagnoses Hardware Faults 

    -> Step 5: Laptop Is Repaired or Replaced 

        Issue Fixed By Replacing RAM 

        Replacement Device Provisioned From IT Inventory (Stockroom)

    -> Step 6: Ticket Closed 

        Employee Who Raised Ticket, Confirms Issue Resolved 

        IT Team Closes Ticket & Satisfaction Survey Sent

    -> platform-as-a-service 

        -> Platform as a service (PaaS) or application platform as a service (aPaaS) 
        is a cloud computing service model.

        -> https://en.wikipedia.org/wiki/Platform_as_a_service

        -> platform-based service is a" cloud computing service model" where 
        users provision, instantiate, run and manage a modular bundle of a 
        computing platform and applications, "without the complexity" of 
        building and maintaining the infrastructure associated with 
        developing and launching application(s), and to allow developers 
        to create, develop, and package such software bundles.

    -> To Get Started With ServiceNow, We Need ServiceNow Instance. 

    -> What Is An Instance - Cloud     

        -> An instance in cloud computing is a virtual server (virtual machine) 
        running on a cloud provider's physical infrastructure, 
        acting as a dedicated resource for running applications, databases, or websites.
        (ec2-54-204-39-100.compute-1.amazonaws.com)

    
    -> What Is An Instance - ServiceNow

        -> A ServiceNow Instance is a single-tenant copy of the ServiceNow platform 
        hosted in the cloud, accessible via a unique web address 
        (typically https://<instancename>.service-now.com)

        -> When You Are Accessing ServiceNow, you are Accessing an 
        Instance Of The Platform. 

        -> An Organization Can have Multiple Instances 

            -> Development Instance - New Features Development 

            -> Test Instance - Test Features Developed (QA - Check Passed)

            -> Production Instance - Live Data (Customers)
